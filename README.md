# WE Sighting Studio workflow

[Open the public interactive walkthrough](https://mark48-50.github.io/we-studio-workflow/)

Public, standalone interactive documentation for the Wild Excursions Android app.

This repository contains only the workflow visualization: HTML, CSS and vanilla JavaScript. It uses no ChatGPT APIs, account, iframe wrapper, remote fonts or third-party scripts. Open `index.html` through any static HTTP server, or use the GitHub Pages site.

The app source remains in a separate private repository. The walkthrough processes no actual sightings and publishes no posts.
